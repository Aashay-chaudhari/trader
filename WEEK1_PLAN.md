# Initial Operating Checklist

The original dual-profile week-one plan has been completed and superseded by the Codex-only operating model.

## Daily

- Run morning research before the open.
- Confirm the validated cache reaches `main`.
- Observe scheduled monitor runs and paper account activity.
- Run evening reflection after the close.

## Weekly

- Run the weekly review.
- Review trade quality, skipped setups, risk usage, and proposal backlog.
- Verify GitHub Pages interaction links and portfolio history.

## Monthly

- Run the monthly retrospective.
- Reassess strategy effectiveness and regime rules.
- Run an evolution review when the proposal backlog has enough evidence.

## Success Criteria

- Local sessions are recorded and published.
- Scheduled monitor runs consume the latest morning plan.
- Paper orders respect risk limits.
- Dashboard state matches durable Codex profile state.
- Failures are visible in Actions, retained artifacts, and interaction logs.
